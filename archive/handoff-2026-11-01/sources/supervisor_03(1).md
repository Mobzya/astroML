# Руководителю — этап 3

Фактический исход: **A — локальное улучшение надёжности при сопоставимом coverage**. Вывод ограничен новой controlled simulation.

Реально выполнено: аудит 15600 rows этапа 2; новые 1200 независимых latent pairs,
train/validation/calibration/evaluation/stress;49 observation-only features;
A–F и четыре абляции/score-only comparator; CPU main477.3s,
300 pair-bootstrap, таблицы/шесть графиков и независимая проверка 24120 fitted rows.
GPU/платные сервисы не запускались, reserved test закрыт.

| Brier | 0.134 [0.130; 0.137] | 0.112 [0.108; 0.116] |

H3.1 поддерживается на ID по этому критерию; H3.2 поддерживается на ID по MAD; H3.3 поддерживается для E против B на ID при coverage80%.
H3.4: audit показывает существенную потерю различающего сигнала: peak40 median d=.687,
oracle mean error29.7% против 0.4% на полном ряде. Это не доказательство невозможности
для composite задачи и не требование восстановить отсутствующий сигнал нейросетью.

Неожиданное/отрицательное: удаление optimizer features не дало убедимого изменения
Brier; точная сходимость не стала универсальным признаком надёжности. На неизвестных
periodic negatives LR дала FPR40% при random40; на OOD SNR3/random40 RF дала
FPR27.5%, а среди принятых negatives60%. Простой отказ не убирает уверенные FP.
На peak40 RF coverage53.75%, selective error40.31% — этот режим не решён.

H3.2 количественно: mean |FPR−5%| по ID падает 4.72→2.75 процентного пункта, но
максимальный achieved FPR условного метода 10.28%. Строгий контроль 5% не достигнут.
H3.1–H3.3 поддержаны локально на ID; универсальная переносимость и польза отдельной
группы optimizer-uncertainty не установлены. H3.4 имеет диагностическую поддержку;
информационная невозможность неизвестной composite задачи не доказана.
Все seed опубликованы; методы/пороги не выбраны по evaluation. Стандартные
LR/RF/calibration/reject option не объявляются новыми. Подробности — §12 полного отчёта.

Недостоверно распространять числа на реальные обзоры, prevalence редкого события,
строгий FPR1%, неизвестные noise/negative families. CI условны на обученных моделях;
100cal sources/seed мало для точных хвостов. MulensModel независимая сверка пока
пропущена; новые внешние negative stress остаются синтетическими.

Наиболее ценный следующий шаг определяется отрицательными stress-результатами:
source-disjoint калибровка отказа на расширенном negative pool и noise shifts с
сохранённой новой evaluation; сравнить с простым confidence RF при coverage≥80%.
До CNN необходимо проверить переносимость reliability, не расширять архитектуру
ради восстановления пропущенного пика. Согласовать с руководителем FP/FN cost,
допустимый coverage и источник реальных licensed negatives.
