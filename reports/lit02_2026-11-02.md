Negative control: для фиксированного residual с mean(r²)=1 полная NLL по проверенной сетке минимальна при variance=1. Только quadratic loss продолжает уменьшаться до variance=100 — конкретная демонстрация недопустимости опускать logdet при оценке шума.

Условный GP на фиксированном noiseless PSPL residual способен объяснять всё большую долю кривой при увеличении амплитуды. Полная likelihood также штрафует чрезмерную гибкость; это механизм возможной конкуренции GP/physical mean, не измерение detector FPR или частоты ошибок.

Итог для протокола: полная Gaussian likelihood, Cholesky, одинаковое noise family для competing means, явные bounds/failures, отдельный absorption control. Оптимизация гиперпараметров не равна их интегрированию. Новая evaluation не генерировалась.
