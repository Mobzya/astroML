# Внешний pilot: NOT_RUN, аудит завершён

Дата: 03.11.2026. Задача `W1-REAL-AUDIT`, кампания `week-2026-11-03-09`.

Рассмотрены ровно два кандидата — OGLE-IV EWS 2026 и ZTF public DR24. [Data card](../research/external_data_card.md) содержит проверенные первичные сведения, неизвестные поля и наши отдельно обозначенные выводы. [Access manifest](../research/reading_notes/external_source_access.json) фиксирует версии, охват чтения, доступные SHA и неуспешные обращения.

| Проверяемое условие | Итог аудита | Следствие |
|---|---|---|
| Известна полезная форма фотометрии и временные оговорки | Частично; неизвестные явно перечислены в data card | Нельзя молча передать новые кривые существующему синтетическому fitter |
| Имеются проверенные PSPL и независимые отрицательные labels | Не установлено для выбранных продуктов | Классификационные recall/FPR на обзорах здесь невозможны |
| Установлен независимый source-level split | Только требования; crossmatch не выполнен | Нельзя объявить разные каталожные ID независимыми источниками |
| Ясные условия предполагаемой публикации | OGLE требует предварительного контакта; для ZTF проверены указания в выбранных docs, отдельная redistribution license не установлена | OGLE raw не использовать в опубликованном опыте без разрешённого урегулирования; ZTF не объявлять запрещённым |
| Bounded доступ | 0 кривых из максимума20; 4 точечных запроса к документам, web-прочтение выбранных разделов | Нет массового скачивания, логинов, платных ресурсов или писем |

**Решение: NOT_RUN внешнего классификационного опыта.** Это допустимый acceptance outcome именно документального аудита. Точность на телескопных данных не измерена; синтетические COV06 raw и пороги не менялись по внешней документации.

Проверка состава артефактов [external_audit_verifier.json](checks/external_audit_verifier.json) относится к полноте/согласованности записей и отсутствию выдуманного опыта; она не является независимой проверкой условий обсерваторий, меток или временных преобразований. Полный чужой текст не распространяется. Код нового классификатора/конвертера, seed и runtime обучения неприменимы: запусков не было. Длительность HTTP-доступа отдельно не измерялась и записана как неизвестная; научный fitting runtime равен нулю.

Для будущего этапа сначала нужны разрешённая постановка и labels, после этого frozen data-access/split/quality/time protocol и минимальная численная проверка преобразования. Документальный аудит не разрешает расширять недельную задачу до нового telescope benchmark.
